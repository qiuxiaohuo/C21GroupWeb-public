# 细观力学

这里的文档旨在将经典但繁多的细观力学方法整理成**对象清晰**的计算公式，对象清晰是指应当说明方法的适用范围，例如是否可用于计算不同夹杂形状的多相问题等等。文档所有的计算公式都将给出明确的输入和输出，可直接用于编程实现。在上述宗旨下，这一组文档的核心内容是**等效模量的估计方法**，而其它文档均是为了使读者更好地理解这些估计方法。具体地讲，

1. Eshelby 张量构成所有解析估计方法的内核，因此在 **Eshelby 张量的计算方法**下给出特殊夹杂形状的 Eshelby 张量解析公式，和一般各向异性介质内椭球形夹杂 Eshelby 张量的数值公式。
2. 估计得到的等效模量应具有八种弹性材料对称性的其中一种对称性，而这直接继承了夹杂的几何对称性和组分的材料对称性。在**材料和几何的对称性**中对此进行讨论，并给出在对称性假设下的张量简化运算方式。
3. 对一种等效模量估计方法，若证明对应某一种可实现的（attainable）微结构，则其结果必然在 Hashin--Shtrikman 变分原理（HS 变分原理）提供的上下界之间。因此常用 HS 变分原理得到的上下界检验某种估计方法的合理性。在**等效模量的上下界**给出 HS 变分原理的详细推导过程。
4. 等效模量估计本质上是求解线弹性边值问题，对一些特殊的几何区域，例如同心球、同心圆柱、层合板等等，其全场的应变场可以解析求解。在**特殊几何域的解析解**给出一些这样的例子。
5. 此外，在**其它**中给出一些和细观力学相关，但理论性较强的文档。
