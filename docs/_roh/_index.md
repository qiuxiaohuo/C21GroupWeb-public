# 简介

我拟定的博士论文题目为**多尺度降阶均质化的影响张量计算方法**，以降阶均质化的影响张量计算过程，陈述如下主题：

1. 建立降阶均质化和其它多尺度方法的联系
2. 探索降阶均质化方法的边界，说明其何不可为


为实现上述主题，拟定的博士论文框架为

1. 陈述降阶多尺度方法的基础，包括数学渐进均质化，以及处理材料非线性的 TFA 方法。描述与 NTFA，SCA，有限元方法的区别。
2. 阐述降阶多尺度的修正方法。包含热力学一致和假设应变，给出 limit case 下的细观力学解释，以及验证
3. 修正后降阶多尺度方法的具体应用。


我希望能用一组短小的 Markdown 文档，组织起一个大的论文框架。但这可能有如下不方便的地方：

1. 交叉引用。包括跨文档引用公式、引用文献和图表等。markdown 不支持 `\section` 和 `\section` 引用，跨文档的公式编号无法正确引用。Markdown 不支持文献引用命令 `\cite`，以及对图表设置标签。
2. 公式环境。Markdown 不支持子公式，公式环境可能无法做到和 LaTeX 无缝对接。


我认为我可以做的撰写论文工作流为：

1. 首先写一组 Markdown 文档，关注内容。其中跨文档引用公式仍使用 `\eqref{}`，即使公式编号无法正常显示。图表暂时使用 Markdown 语法，可以用 GPT 转换为 LaTeX 语法。图表使用加粗的段落文字给出说明。按照 `\ref{}` 语法引用图表，即使在 Markdown 中无法正常显示。文献引用使用 Elsvier 格式，在插入到 LaTeX 之后切换成 bibLaTex 引用。
2. 然后将 Markdown 文档转移到 LaTeX 中，调整适配于 LaTeX 的公式环境，转换插入图表的环境。这时应注重排版。转移后文档内容的修改只在 LaTeX 进行，不再更新 Markdown 文档。


为方便论文后续的修改和调整，我遵循如下一致性规范：

1. 公式环境均使用 `equation`，公式编号使用 AMS 规则，即只对引用的公式进行编号。所以公式环境中要么设置 `\label{eq:}`，要么设置 `\notag`。复杂公式使用可独立编译的 LaTeX 代码生成公式之后，截图插入文档中，并设置一个 pseudo 引用指向这个公式。
2. 在撰写论文中可能还有一些叙述比较模糊的地方，但是为了推进论文整体的面貌需要暂时跳过。这时使用 Markdown 的引用环境记录自己的困惑、进一步阅读的文献等等
