# 简介

拟定的博士论文题目为**多尺度降阶均质化的影响张量计算方法**，拟定的博士论文框架为

1. 陈述降阶多尺度方法的基础，包括数学渐进均质化，以及处理材料非线性的 TFA 方法。描述与 细观力学、NTFA、SCA 等方法的区别。
2. 给出影响张量修正方法框架。包含宏观材料对称性、热力学一致性和宏细观能量一致性。
3. 修正后降阶多尺度方法的具体应用。
